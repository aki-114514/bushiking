# ブシキング アプリ化キット

戦国武将と技カードで戦う、刀・弓・槍のジャンケン勝ち抜きバトルです。
このフォルダには、ゲームをアプリとして使うためのファイルが入っています。

```
bushiking-app/
├─ www/                  ← ゲーム本体（このフォルダだけでアプリとして動きます）
│  ├─ index.html          ゲーム
│  ├─ manifest.webmanifest アプリ名・アイコン・全画面表示の設定
│  ├─ sw.js               オフラインでも起動できるようにする仕組み
│  └─ icons/              アプリのアイコン
├─ capacitor.config.json ← ストア用アプリを作るときの設定
├─ package.json
└─ README.md
```

---

## 方法1：ホーム画面に置くアプリにする（いちばん簡単・無料）

スマホのホーム画面にアイコンが並び、タップすると全画面のアプリとして起動します。
一度開けば、電波がなくても遊べます。

### 1. `www` フォルダをネットに公開する

アプリとしてインストールするには、HTTPS のアドレスで公開されている必要があります。
無料で使える方法を2つ挙げます。

**Netlify Drop（ドラッグするだけ）**
1. パソコンで https://app.netlify.com/drop を開く（無料のアカウント登録が必要です）
2. `www` フォルダをそのページにドラッグ＆ドロップする
3. 表示されたアドレス（`https://〜.netlify.app`）がゲームのアドレスです

**GitHub Pages**
1. GitHub で新しいリポジトリを作り、`www` の中身をアップロードする
2. リポジトリの Settings → Pages で、公開するブランチを選んで保存する
3. 表示されたアドレス（`https://ユーザー名.github.io/リポジトリ名/`）がゲームのアドレスです

### 2. スマホでインストールする

- **iPhone**：Safari でゲームのアドレスを開く → 共有ボタン → 「ホーム画面に追加」
- **Android**：Chrome でゲームのアドレスを開く → 右上のメニュー → 「アプリをインストール」または「ホーム画面に追加」

## 方法2：App Store・Google Play で配るアプリにする

`www` フォルダを Capacitor（ウェブのゲームをスマホアプリに包む無料の道具）で包みます。

### 必要なもの
- パソコンに Node.js
- Android 版：Android Studio
- iPhone 版：Mac と Xcode
- ストアで配るには、Google Play と Apple Developer Program への開発者登録（登録料がかかります。金額は各公式サイトで確認してください）

### 手順
1. `capacitor.config.json` の `appId` を、自分だけの名前に変える（例：`jp.yourname.bushiking`）。ストアに出すと変更できないので最初に決めます。
2. このフォルダでターミナルを開き、次を実行する
   ```
   npm install @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios
   ```
3. Android 版：`npm run android` → Android Studio が開くので、実機かエミュレーターで実行
4. iPhone 版（Mac のみ）：`npm run ios` → Xcode が開くので、実機かシミュレーターで実行
5. ゲームを直したら `www` を差し替えて `npm run sync`

## 知っておくこと

- **セーブデータ**：集めたカードや設定は、その端末のそのアプリの中に保存されます。ブラウザで遊んだ分とホーム画面のアプリの分は別々です。
- **文字フォント**：初回はネットからフォントを読み込みます。オフラインで初めて開いたときは、端末の標準フォントで表示されます。
- **音**：最初に画面をタップしたときから鳴ります（スマホの決まりです）。
- **掛け声の声ファイル**：読み込んだ声はその端末の中だけに保存されます。ストアで配る場合、声素材は「アプリへの同梱・配布」が利用規約で認められているものを使ってください。
- **パソコンで試すだけなら**：`www/index.html` をダブルクリックしても遊べます（オフライン機能だけは公開したときに働きます）。
